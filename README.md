# Interactive Song Archive

An interactive archive showing the evolution of **Come What May Tomorrow** across five versions.

## Files

- `index.html` — page structure
- `style.css` — responsive layout and styling
- `script.js` — timeline, crossfading audio, playback and waveform
- `assets/audio/` — five song versions
- `assets/images/album-art.jpg` — album artwork

## GitHub Pages

1. Upload the contents of this folder to the root of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The site uses only local files and browser Web Audio APIs, so no build step or server-side code is required.
